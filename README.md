# Type Zero – Open Source Modul Generator

Type Zero ist ein modulares Wohnsystem, entworfen für den Ersatz der ersten Häuserreihe an der Engstringerstrasse in Schlieren Nord (ETH Entwurf). Es gibt keinen festen Grundriss, sondern ein Regelwerk: Jede Anordnung, die alle Regeln erfüllt, ist ein gültiges Gebäude.

Die Seite zeigt geprüfte Varianten für drei Blockgrössen (Breite/Länge/Höhe in Modulen zu 4 x 4 x 3 m), Ebene für Ebene, und rechnet auf Wunsch neue.

| Block | Wohnungen A B C D | Gültige Varianten | Gebäudeformen |
| --- | --- | --- | --- |
| 3/5/6 | 4 5 5 2 | 1'879'346'752 | 50'133'504 |
| 3/4/6 | 3 4 4 2 | 2'627'008 | 112'288 |
| 3/3/6 | 3 3 3 1 | 74'112 | 3'664 |

## Dateien

- `index.html` – die Seite (3D-Ansicht, Grundriss, Bedienung)
- `generator.js` – Regelwerk, Zufallsgenerator und Prüfung jeder Variante
- `varianten.js` – Vorrat geprüfter Varianten

Lokal ansehen: `index.html` im Browser öffnen.
